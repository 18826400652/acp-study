## 1. 审计结论与范围

现有模拟题的检索诊断、提示词迭代、工具调用和安全防护已有较多覆盖。扩充时应优先补充完整 Token 账单计算、长期 API 密钥安全、多轮追问的检索适配、专家评测校准、训练基础与独立评估、蒸馏路径及收益测算、固定流程选型、多模态完整链路和业务落地效果。

现有题目有一部分集中在教程工具或文件细节，例如 AgentScope 配置、QWEN.md 层级、训练产物目录和端口选择。这些题可以用于实操复习，但不能据此认定 V4 的能力范围已被完整覆盖。新增题优先考查决策条件和诊断证据。

本次阅读了 V4 四页内容、20 道截图，以及 150 道模拟题的题干和正确选项，针对拟补内容检查了课程相关章节。这里是**内容覆盖审计**，不是对原有 150 道题的完整事实纠错，也不是官方押题或考试通过率预测。

以下“充分覆盖”仅表示相应能力已有多种直接题例；“薄弱”表示仅有部分子项、跨模块间接覆盖或操作细节题；“未直接覆盖”表示未找到明确考查该能力的原题。状态只针对扩充前的 150 道模拟题，待确认样题不计入已入库覆盖。

截图中的选中状态、答案文字和橙色评审说明分属不同信息，不能将选中项直接当作正确项；有的选项边界也需要额外限定。本次仅将其作为题风参考，不把截图批注视作权威知识来源。
