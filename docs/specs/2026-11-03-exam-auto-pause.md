# 模拟考试退出暂停计时修复

日期：2026-11-03。范围：ACP 模拟考试。

## 问题与原因

倒计时原先始终计算“当前时间－开考时间”。离开考试页时虽然清理了刷新定时器，但没有记录暂停；重新进入时，离开期间也算入120分钟，并可能立即自动交卷。

## 修复行为

- 离开考试页、切换题库、页面进入后台或触发pagehide时，保存答案和累计答题时间并暂停。
- 返回考试页、恢复前台或从页面缓存恢复时，继续剩余时间。取消离开仍保持计时。
- 刷新或重新打开只恢复最近保存的答题时间，不计算应用关闭期间。答题过程中每秒写入计时检查点；pagehide及visibilitychange即时保存。
- 实际答题达到120分钟时仍自动交卷，且只交卷一次。成绩中的“用时”统计累计答题时间，开考、交卷日期仍保留原始时间戳。
- 规则页及离开确认框明确说明自动暂停。
- 暂停时出现的更新提示，在恢复答题后点击时会重新核对考试状态，避免答题中触发刷新。

## 进度兼容

保持schemaVersion=1，草稿新增elapsedMs（已累计毫秒）及runningSince（本段开始时间，暂停时null）；成绩新增durationMs。恢复草稿时保留elapsedMs并置为暂停，进入考试页才继续。

旧版未交卷草稿只有startedAt，无法还原其中的离开时长；升级时保留题目与答案，赋予完整120分钟，不按历史墙上时间强制交卷。旧成绩缺少durationMs时继续使用原起止时间显示，不重算历史得分。

可选计时字段纳入导入校验，拒绝负数、非数值和无穷值；旧版导入继续兼容。
